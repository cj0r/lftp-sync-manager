LFTP Transfer Manager Guide

Overview

This application manages high-speed automated transfers between a remote SFTP server and your local directories. It uses LFTP to accelerate speeds through multi-segmented (pget) and parallel connection threads.

Required Docker Volume Mounts

For file transfers and configuration persistence to work, ensure these directories are mapped in Docker:

Container Path Description & Mapping
/config Stores settings, logs, public/private keys, and history (e.g., /mnt/user/appdata/lftp-gui).
/local-push Folder containing files to upload/push (e.g., /mnt/user/appdata/lftp-gui/upload).
/local-pull Folder where downloaded files are saved (e.g., /mnt/user/appdata/lftp-gui/download).

Automated SSH Key Authentication

Using SSH key-pair authentication is the recommended method to secure connection credentials and prevent plain-text passwords from being stored in configuration files.

In-App Handshake
  1. Open the Connection Settings drawer.
  2. Click Generate Key-Pair. The app will create a 4096-bit RSA key inside your persistent /config folder.
  3. Enter your SFTP password in the Connection settings input.
  4. Click Authorize on Remote Host. The app automatically logs in, configures remote directory permissions, and appends the public key to ~/.ssh/authorized_keys on the remote server.
  5. Once authorized, **delete the password from the settings form** and click Save. The app will now authenticate passwordlessly!

Manual SSH Key Setup

If you prefer to configure authentication manually, you can mount your existing SSH directory inside the container's volume mounts:

Mount path: ~/.ssh:/root/.ssh:ro (Read-only)
Ensure your private key file has secure permissions on the host system: 
chmod 600 ~/.ssh/id_rsa

Performance Parameters

  • Parallel Files: The maximum number of files transferred simultaneously. Excellent for small files.
  • Segments per File: Divides large files into pieces that download/upload concurrently, bypassing single-thread rate limits.
