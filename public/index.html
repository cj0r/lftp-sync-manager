LFTP Transfer Manager Guide

Overview

This application manages fast automated transfers between a remote SFTP server and your local directories. It uses LFTP, a high-performance file transfer program, to accelerate speeds through multi-segmented (pget) and parallel connection threads.

Sync Direction Flow

  • Pull (Remote to Local): Downloads files from the SFTP server to your local directory. After files are successfully transferred, they are automatically removed from the SFTP server.
  • Push (Local to Remote): Uploads files from your local directory to the SFTP server. After files are successfully transferred, they are automatically removed from your local directory.

Key Configuration Settings

  • Parallel Files: The maximum number of files transferred at the same time. Too high may get you blocked by the host.
  • Segments per File: Splits large files into sub-chunks to download/upload them in parallel. Excellent for bypassing rate limits.
  • SSH Key Mounts: If using passwordless SSH keys, place them in the host's ~/.ssh folder. The Docker container mounts this folder to /root/.ssh automatically. Make sure key permissions are secure (e.g. chmod 600).

Advanced: Container Environment Variables

The Docker container can be customized using the following environment variables:

Variable Default Description
PORT 9342 The web GUI server port.
CONFIG_DIR /config Persistence directory for configurations.
PUID / PGID 99 / 100 Linux User ID & Group ID mapping for file ownership.
TZ UTC Container system timezone (e.g. America/New_York).
